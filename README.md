У цій частині програми оголошуємо змінні для збереження введених значень `a`, `N` та результату обчислення суми `S`. Початкове значення суми дорівнює 1 відповідно до формули із завдання.

```c
int N;
double a, S = 1.0;
double power = 1.0;
```

Далі просимо користувача ввести значення `a` та `N`. Також перевіряємо, чи є N допустимим значенням.

```c
printf("Enter a: ");
scanf("%lf", &a);

printf("Enter N: ");
scanf("%d", &N);

if (N < 1) {
    printf("Error: N must be greater than or equal to 1.\n");
    return 1;
}
```

У цій частині коду виконуємо обчислення суми ряду за формулою, використовуючи цикл `for`, який проходить від 1 до N.

```c
for (int n = 1; n <= N; n++) {
    power *= a;

    double denominator = a + n;

    if (denominator == 0.0) {
        continue;
    }

    if (n % 2 == 0) {
        S += power / denominator;
    }
    else {
        S -= power / denominator;
    }
}
```

Для обчислення степеня `a^n` я не використовую стандартну математичну функцію `pow()`. Замість цього застосовую множення попереднього значення на `a` під час кожної ітерації циклу.

```c
power *= a;
```

Також перевіряємо знаменник `a + n`. Якщо він дорівнює нулю, поточний член ряду пропускається за допомогою `continue`.

Для чергування знаків використовується перевірка парності числа `n`: якщо воно парне, член додається до суми, якщо непарне — віднімається.

В кінці програми виводимо отриманий результат:

```c
printf("The sum of the series is: %.10lf\n", S);
```

Спочатку оголошуємо функції, які будуть використовуватися для виділення пам'яті, введення елементів, обчислення сум рядків, сортування та виведення матриць.

У цій частині коду користувач вводить розмір матриці N. Також перевіряємо, чи правильно введено значення та чи є воно більшим за нуль.

```c
int N;

printf("Enter matrix size N: ");
if (scanf("%d", &N) != 1 || N <= 0) {
    printf("Error: N must be greater than 0.\n");
    return 1;
}
```

Далі виділяємо динамічну пам'ять для двох матриць A та B за допомогою функції `memory_alloc()`. Після цього перевіряємо, чи вдалося виділити пам'ять.

```c
double **A = memory_alloc(N);
double **B = memory_alloc(N);

if (A == NULL || B == NULL) {
    printf("Memory allocation error.\n");

    if (A != NULL) clear_memory(A, N);
    if (B != NULL) clear_memory(B, N);

    return 1;
}
```

Функція `memory_alloc()` виділяє пам'ять окремо для масиву вказівників та кожного рядка матриці. Якщо виділення пам'яті не вдалося, вона звільняє вже виділену пам'ять та повертає `NULL`.

```c
double **memory_alloc(int N) {
    double **Arr = (double **)malloc(N * sizeof(double *));

    if (Arr == NULL) {
        return NULL;
    }

    for (int i = 0; i < N; i++) {
        Arr[i] = (double *)malloc(N * sizeof(double));

        if (Arr[i] == NULL) {
            for (int j = 0; j < i; j++) {
                free(Arr[j]);
            }
            free(Arr);
            return NULL;
        }
    }

    return Arr;
}
```

Після виділення пам'яті заповнюємо початкову матрицю A. Користувач вводить кожен елемент окремо за допомогою клавіатури. Для цього використовується функція `fill_arr()`.

```c
void fill_arr(double **Arr, int N) {
    for (int i = 0; i < N; i++) {
        for (int j = 0; j < N; j++) {
            printf("Enter element [%d][%d]: ", i, j);
            scanf("%lf", &Arr[i][j]);
        }
    }
}
```

Для обчислення суми елементів окремого рядка використовується функція `row_sum()`. Вона проходить по всіх стовпцях заданого рядка та додає значення кожного елемента до змінної `sum`.

```c
double row_sum(double **Arr, int row, int N) {
    double sum = 0;

    for (int j = 0; j < N; j++) {
        sum += Arr[row][j];
    }

    return sum;
}
```

Основна робота із сортуванням виконується у функції `sort_matrix()`. Спочатку копіюємо всі елементи початкової матриці A у матрицю B, щоб не змінювати оригінал.

```c
for (int i = 0; i < N; i++) {
    for (int j = 0; j < N; j++) {
        B[i][j] = A[i][j];
    }
}
```

Після копіювання виконуємо сортування рядків матриці B методом бульбашки. Для цього порівнюємо суми сусідніх рядків за допомогою функції `row_sum()`. Якщо сума поточного рядка менша за суму наступного, ці рядки міняються місцями.

```c
for (int i = 0; i < N - 1; i++) {
    for (int j = 0; j < N - 1 - i; j++) {

        if (row_sum(B, j, N) < row_sum(B, j + 1, N)) {

            double *temp = B[j];
            B[j] = B[j + 1];
            B[j + 1] = temp;
        }
    }
}
```

Для обміну рядків використовується тимчасовий вказівник `temp`. Він дозволяє поміняти місцями цілі рядки матриці без копіювання кожного елемента окремо.

Після завершення сортування виводимо обидві матриці на екран за допомогою функції `print()`. Спочатку виводиться початкова матриця A, а потім відсортована матриця B.

```c
print(A, N, 'A');
print(B, N, 'B');
```

Сама функція `print()` проходить по всіх рядках і стовпцях матриці та виводить її елементи з точністю до двох знаків після коми.

```c
void print(double **Arr, int N, char name) {
    printf("\nMatrix %c (%dx%d):\n", name, N, N);

    for (int i = 0; i < N; i++) {
        for (int j = 0; j < N; j++) {
            printf("%8.2lf ", Arr[i][j]);
        }
        printf("\n");
    }
}
```

Наприкінці програми звільняємо динамічно виділену пам'ять для обох матриць за допомогою функції `clear_memory()`. Вона звільняє пам'ять кожного рядка, а потім сам масив вказівників.

```c
void clear_memory(double **Arr, int N) {
    for (int i = 0; i < N; i++) {
        free(Arr[i]);
    }

    free(Arr);
}
```
